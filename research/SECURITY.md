# Publication review scope

This is an allowlisted new code snapshot. Original Git history, original research ZIPs, full dissertation files, student records, private conversations, identity mappings, rater declarations/signatures, course full texts, external weights, fonts, credentials and databases are excluded.

Before the first commit, all proposed public files were reviewed by source category and scanned with finite static patterns for private paths, emails, credential literals, token shapes, private keys, unexpected binaries and unsafe file types. Independent component reviews inspected numerical-data fields, real prompt packages and offline wrappers. No professional secret scanner was installed; the checks have finite detection scope and do not guarantee that every possible privacy or secret issue is detectable.

Source maps preserve hashes before and after documented publication adaptations. Private path metadata was replaced by explicit external-input locations; model-visible prompt content and parameters were retained. Anonymous numeric rows preserve their defined input level. Transcribed third-party rubric prose without established redistribution permission was excluded while retaining local operational anchors and attribution.

The default reproduction installs no model or client and denies network transport within its Python process. Synthetic module tests use invented inputs and temporary stores. Release verification includes an independent clone of the actual GitHub tag and download/hash verification of public assets. Local review receipts are not public release assets.

No push protection is bypassed. Tags are fixed snapshots; future corrections or supplements must use a new version.
