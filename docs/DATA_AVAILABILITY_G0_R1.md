# Actual data availability

The repository includes no-key runtime datasets, true saved final answers and course corpus, anonymized dashboard files, original read-only Memory seeds, and separate evaluation Gold. data/manifest.json binds their publication hashes and source transformations.

The complete authorized research archive is distributed as an uploaded Release asset only after its manifest states PUBLISHED_PUBLIC_DOWNLOAD_VERIFIED. It includes original learning/course publication copies, final41, ratings,40 anchors, S7/R7/D9, latest actual W9 thesis/supplement and source-labelled legacy/DEV inputs/results/small model heads. Its PUBLIC_FILE_MANIFEST.json lists exact member hashes and excludes itself from the list.

A locally assembled ZIP is not evidence of public availability. Release and anonymous download receipts are recorded separately from code commit, CI, local app tests, Community Cloud and real live inference.
